# Statistical Methodology

The statistical engine is the authoritative calculator of the Airfare Price Index.

## Elementary Level

Use price relatives between comparable observations and the documented Jevons / short-index methodology.

## Higher Aggregation

Route/segment indices are aggregated using the prescribed/reference weighting methodology. Official weights must not be invented.

## Booking Windows

Maintain separate indices for T+1, T+7, T+15, T+30 and T+45.

## Reproducibility

Index outputs should retain:

- observation set/version
- basket version
- weight version
- methodology/calculation version
- calculation timestamp

## Validation

Run the index algorithm over the appropriate historical/reference data for the 30-day back-test and calculate the documented validation metrics.
