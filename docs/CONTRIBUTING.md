# Contributing

1. Pull the latest `main`.
2. Create a feature branch.
3. Make focused changes within your module.
4. Add/update tests.
5. Update relevant documentation.
6. Open a pull request.
7. Get review for shared-contract changes.

## Commit Examples

- `feat(statistical-engine): add Jevons calculation`
- `test(statistical-engine): add aggregation tests`
- `feat(data-quality): add fare normalization`
- `docs: update API contract`

## Shared Contract Changes

Discuss changes affecting database schema, shared fare schema, API responses, route/weight configuration, or methodology/versioning with the affected teammate before merging.
