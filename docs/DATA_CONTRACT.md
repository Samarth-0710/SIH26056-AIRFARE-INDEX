# Shared Data Contract

Placeholder for the team's finalized shared contract.

The statistical engine expects cleaned/comparable observations, not raw scraped records.

Relevant dimensions include:

- origin
- destination
- travel date
- observation/search date
- lead time / booking window
- airline
- flight
- departure time
- cabin
- fare class/type
- baggage/fare characteristics
- comparable total fare
- source
- observation timestamp
- quality/status

The exact field names, types, nullability and database/API representation must be finalized against the existing implementation.
